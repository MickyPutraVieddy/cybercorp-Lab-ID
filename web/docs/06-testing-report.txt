Browser test caveats
- Several first waits used English text after Indonesian locale had persisted. Those waits timed out on the language mismatch; a fresh accessibility snapshot showed the expected Indonesian content. This was a test expectation mismatch, not an application exception.
- The first newsletter submit attempt was blocked by the open mobile navigation overlay. Closing the menu and repeating the observed form interaction succeeded.
- No runtime exceptions were reported by the browser console during the inspected flows. These were manual browser spot checks, not a full automated accessibility suite or cross-browser matrix.

Not tested / not implemented

- High-volume/performance testing, full keyboard-only audit, automated WCAG/axe scan, screen-reader testing, real device matrix, legal/commercial review, or production security assessment.
- PostgreSQL Compose sample was not started. No external free-tier account or deployment was created.
